# 🏇 ULTIMATE KEIBA FINAL  
― 週末開催を制圧せよ ―  

Live Demo:  
https://doraiso.github.io/ultimate-keiba-final/

---

## 概要

ULTIMATE KEIBA FINAL は、  
JRA開催構造と公式カレンダーデータを解析し、  
**今週末に開催される競馬場・メインレース情報・補正済み馬番** を即座に提示する  
軽量・自動更新型の競馬支援ツールです。

開催地・日付・グレード情報に加えて、  
中央競馬10場それぞれの月別傾向をざっくり反映し、  
単なる完全ランダムではない **開催場×月ベースの重み付き馬番抽選** を行います。

---

## 主な機能

### 📅 週末開催地の自動判定
- JRA公式カレンダーJSONを解析
- ローカル開催（小倉・中京など）対応
- 週末開催構造を正確に抽出

### 🏆 重賞レース検出
- 該当日のグレードレースを自動判定
- GI / GII / GIII 判別
- 未来の重賞誤表示を防止

### 🎯 レース表示エンジン
- 当日の開催構造に基づきレース一覧を生成
- 重賞開催時はメインレースを強調表示
- 重賞がない日でも正常動作

### 🎲 開催場×月の重み付き馬番抽選
- 東京・中山・京都・阪神・中京・福島・新潟・小倉・札幌・函館の中央10場に対応
- 1月から12月まで、全競馬場の月別補正パターンを定義
- `flat / inner / outer / middle` の4パターンで馬番を補正
- 枠番ではなく、出走頭数に対する馬番の相対位置で重み付け
- 未定義の開催場や例外ケースは `flat` にフォールバック

補正は、競馬場の大まかなコース特性と開催時期を踏まえた簡易モデルです。  
現在のJRAカレンダーJSONに芝/ダート・距離情報が含まれていないため、  
本ツールではそれらを使わず、開催場と月だけで迷いなく抽選します。

## 設計思想

- 公式データをそのまま活かす構造
- 静的サイトとして最大限軽量化
- 自動更新によるメンテナンス不要設計
- 将来の開催構造変更にも対応可能
- 開催場ごとの癖を、軽量な補正ロジックとして実装
- 見た目はシンプル、内部は実戦向け

---

## 技術構成

- Vanilla JavaScript
- DOM制御
- JRAカレンダーJSON解析
- 開催場×月の馬番重み付け
- GitHub Actions 自動取得
- GitHub Pages 配信

フレームワーク非依存設計。

## データフロー

GitHub Actions  
↓  
JRA公式カレンダーJSON取得  
↓  
data/jra/ に保存  
↓  
フロントエンドが読み込み表示

## 使い方

1. 開催地を選択  
2. レースを選択  
3. 出走頭数を指定  
4. 運命を回す  
5. 開催場×月で補正された馬番を確認
